**The Easter Egg: The Merchants Who Changed the World**

> 世界本来是参差不齐的。这块地盐多，那块地盐少；这个村今年余粮，那个村明年断炊。商业从这道缝里长出来：有人愿意跑一趟，把多的送到少的地方——他赚了差价，两端的人都得了便益。后来，其中最卓越的一些，不满足于搬运现成的东西，他们造出从前没有的东西，把全人类的生活改写了一遍。他们是宇宙给人类的一颗彩蛋。

## 主线：落差 + 私利公益

《隐线》问"技术把哪项成本压下去了"。这本书问：**钱和水，是怎么流进普通人生活的。**

答案是一个字：**差**。世界不均衡，有多的地方就有少的地方——这道"多与少"的缝，就是落差。商人是搬运落差的人。

全书分两截：

- **第一部分　商人从哪里来**——统一讲商人为什么出现、有什么意义（货郎搬空间、仓搬时间、招牌搬信任）。搬的是**现成的落差**。
- **后面各部分　制造落差的人**——按时代先后，讲那些先造出一个从没有过的短缺、再去填它的顶级商人。他们推动了科技进步，改变了人类生活。

## 六条定律

1. **落差律**——商业起于不均衡。没有落差就没有交易。
2. **私利公益律**——商人奔的是自己的利，成的却是别人的事。自利是引擎，公益是尾气。
3. **摩擦律**——差价越厚，路上的损耗也越大；商人赚的是跨过摩擦的钱。谁压低摩擦，谁扩大版图。
4. **信任律**——交易最大的摩擦是信不过。谁能降低陌生人之间的信任成本，谁就收得住最高的钱。
5. **组织律**——把人组织起来，本身就能制造落差：分工协作的产出大于个体之和。
6. **彩蛋律**——顶级商人的作品不是某件商品，是一台能持续搬运落差的机器。最大的红利往往不归他们自己——彩蛋不属于下蛋的人。

## 学理支撑（前言《透镜》一章）

主线与六律不是本书杜撰，与经济学关于企业家的经典论述一一对应：

- **米塞斯**（《人的行动》）：企业家是承担不确定性、为判断押上资本的人 → "敢押上身家的冒险者"；
- **哈耶克**（《知识在社会中的运用》）：竞争是发现的过程，价格把分散知识压缩成信号 → "发现落差""信任律""摩擦律"；
- **熊彼特**（《经济发展理论》）：创新、创造性破坏、把发明变成价值 → "制造落差""彩蛋律"；
- **张维迎**（《市场的逻辑》《重新理解企业家精神》）：想幸福先让别人幸福；企业家的两种功能是套利与创新 → "私利公益律"、搬运/制造两截。

## 体例

- 每章一个具体的人或一群人，讲他怎么发现落差、怎么搬运、承担了什么风险。
- 每章设固定栏目「这一趟赚了多少」，回答"这一级的商人靠什么收费"——与《隐线》的「钱在这一级」对应。
- 每章收尾「回头看一眼」五问：落差在哪 → 谁在搬 → 摩擦是什么 → 他赚什么钱 → 抹平后留下什么新落差。
- 史实尽量给年份与可核查的量级；有争议的逸事明确标为「流传的说法」。
- 私利与公益的张力贯穿全书：既不把商人写成圣人，也不写成掠夺者。

## 与《隐线》的关系

《隐线》写"物"——技术如何压低成本；这本书写"人"——谁在落差里谋生，又是谁把谋生变成了改写世界的作品。前者是水，后者是水里的鱼。

## 工程结构

```
draft/     31 个分章 Markdown（正文、附录、参考文献）
media/     cover.png —— EPUB 封面图，1600×2400
output/    构建产物：HTML、index.html（Pages 入口）、EPUB、合并 Markdown
script/    build.py（网页）· build_epub.py（电子书）
```

两行命令重建全部产物：

```bash
python3 script/build.py        # output/*.html + index.html + *.md
python3 script/build_epub.py   # output/*.epub
```

`draft/` 改名或增删章节后，只需改 `build.py` 里的 `ORDER` 与 `PART_SUB`，两个脚本会同步生效。推送 master 后，GitHub Actions 会自动重建并发布到 Pages。
